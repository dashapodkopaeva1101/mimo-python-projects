## 🎮 Проекты

### 1. Камень, ножницы, бумага (Rock, Paper, Scissors)
Простая консольная игра, где игрок соревнуется с компьютером до двух побед.

**Что я использовала:**
- Python (переменные, циклы, условия)
- Модуль random для выбора компьютера
- Счётчик раундов

**Как запустить:**
```bash
cd rock_paper_scissors
python game.py
```

### 2. ToDo-лист (консольный)
Простое приложение для управления списком задач: добавлять, удалять, просматривать.

**Что я использовала:**
- Python (списки, циклы, условия)
- Работа с вводом пользователя
- Бесконечный цикл с точкой выхода

**Как запустить:**
```bash
cd todo_list
python main.py
```
